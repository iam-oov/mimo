6. [x] **Hardcoded Logic Abstraction**:
   - **DECISION**: ✅ `get_isr_table` should **remain as Shared Kernel domain logic**. No abstraction needed.
   - **Rationale**: ISR tables are static fiscal constants published by SAT (Mexican tax authority). They never change at runtime, have no external data source, and are pure functions. This is proper Domain-Driven Design Shared Kernel - domain knowledge shared across bounded contexts (tax_calculation, recommendations).
   - **Alternative considered**: `FiscalDataProvider` port - rejected as over-engineering for static constants.
